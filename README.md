# Fold Atlas · Modified square twist

Interactive atlas of the modified square twist (thin-panel affine model): 16 real closed branches
(B1–B11 through the flat state, R1–R5 elsewhere; each from one complex seed per drive h4, h12, h13), path plot in (h1, h5, h9), 3D configuration at the selected sample, and the flat crease pattern with merge sets.

Online: https://zhulidong97.github.io/fold-atlas/

Second example (two vertices + an off-line vertex, 5 closed branches named by complex seeds): https://zhulidong97.github.io/fold-atlas/dmv3/

Third example (double Miura vertex: 4 closed 1D branches and one 2D sheet; drag on the sheet in the path view or in the 2D control square): https://zhulidong97.github.io/fold-atlas/miura-dmv/

Pages switch through the menu at the top right.
